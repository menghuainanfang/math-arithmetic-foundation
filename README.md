# math-arithmetic-foundation
# 算数基础 - 重构数学学习体系

## 项目简介
大学期间想给自己找一个自己擅长且有意义的事，故尝试将小初高数学内容重新排序，构造一个新的学习体系和学习历程的数学教育项目

## 核心理念
- **不完全课本化**：不再按年级分割知识点，而是按我自己的理解重新编排
- **随心而为**：我会按照我的想法讲解，可能会融入各种超纲或无关的东西
- **尝试学习**：模仿曾经看过的一些博主的视频，顺带还能学习一下视频制作

## 项目结构
- `/lectures`：各章节讲义
- `/exercises`：配套练习题及答案
- `/resources`：教学资源（课件、视频链接等）
- `/tools`：辅助教学工具

## 如何使用
1. 浏览[知识图谱](docs/knowledge-graph.md)了解整体结构
2. 按照推荐的学习顺序阅读讲义
3. 完成配套练习题巩固知识
